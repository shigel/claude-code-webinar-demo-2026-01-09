# PR Review Checklist (Demo)

## Correctness
- Requirements satisfied?
- Edge cases (zero, negative, empty, None)?
- Backward compatibility?

## Risk
- Silent failures?
- Unexpected behavior change?
- Dependency / env assumptions?

## Maintainability
- Names communicate intent?
- Docstrings/comments explain why (not just what)?
- Function boundaries reasonable?

## Tests
- Test proves the bug is fixed?
- Any missing regression tests?
- Fast to run locally?
